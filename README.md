构建一个基于 Airtest​ 的企业级 Android 自动化 RPA 平台，脚本以文件形式存储于本地代码库，运行时动态从 PostgreSQL​ 拉取业务数据驱动执行，并采用 UV​ 作为高性能 Python 环境管理工具，实现灵活、高效的无人值守自动化。

🎯 核心功能描述
1. 自动化引擎 (Airtest Core)

项目将基于 Airtest​ 框架构建核心执行能力，利用图像识别与 UI 控件树（Poco）技术，实现对 Android 应用（包括原生、Flutter、Unity 等）的精准操控。系统将模拟真实用户行为（点击、滑动、输入、手势），支持跨应用跳转及系统弹窗的智能处理，确保自动化流程在无 API 接口依赖的情况下稳定运行。

2. 本地脚本与数据解耦 (Local Scripts & DB Data)

项目采用脚本本地化、数据动态化的设计哲学：

脚本本地存储：所有自动化流程脚本（.py或 .air）均存放于本地项目目录中，便于版本控制（Git）、代码审查及模块化维护。

数据库仅作数据源：PostgreSQL 仅负责存储和管理测试所需的业务数据（如登录账号、商品 ID、测试参数、环境配置等），不作为脚本仓库。脚本运行时实时查询数据库获取数据，实现“一套脚本，万组数据”的灵活复用。

3. 多流程配置化 (Multi-Flow Orchestration)

项目将设计为插件化的流程编排系统。

原子化脚本：将复杂的业务逻辑拆分为独立的原子化脚本（如：login.py、browse.py、checkout.py），存放于本地 flows/目录。

配置驱动执行：通过 YAML/JSON 配置文件定义流程的串联顺序、执行条件和数据映射规则，支持串行、并行或条件分支策略，实现不同业务场景（如回归测试、日常巡检、批量任务）的快速切换。
